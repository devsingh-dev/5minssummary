# 5 Mins Summary 📚

Welcome to **5 Mins Summary**! We distill the world's best non-fiction, business, and self-help books into quick, actionable summaries. Extract the core ideas, save your time, and level up your knowledge instantly.

## 🔗 Live Website
[Visit 5 Mins Summary Here](https://5minssummary.com)

## 🛠️ Tech Stack Used
* **HTML5**
* **Tailwind CSS**
* **JavaScript** (Static Site Generation)

## ✨ Features
* Fast and fully responsive design.
* Real-time search and filter functionalities.
* Dedicated pages for Book Summaries, Affiliate Links, Privacy Policy, and Terms & Conditions.
* SEO optimized static architecture.

## 🚀 How to Run Locally
1. Clone the repository to your local machine.
2. Open the project folder.
3. Open `index.html` or `summary.html` in your web browser.
4. To generate a new book, add the JSON file in the `data/` folder and run `node generate.js` in your terminal.
