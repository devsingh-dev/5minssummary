HOW TO USE THIS TOOL

Creating Realistic UI Depth & Elevation

  1. Set the Light Direction (X & Y Offsets): Keep Horizontal Offset near 0px and push Vertical Offset between 8px and 24px to simulate natural overhead lighting.
  2. Soften with Blur & Negative Spread: Increase the Blur Radius (24px–48px) and apply a negative Spread Radius (-4px to -12px) so the shadow tucks neatly beneath the card.
  3. Tune Color & Opacity: Instead of pure black, pick a dark brand tint (like deep forest green or slate) at 10%–20% opacity for a clean, modern look.
  4. Copy Your Code: Click Copy CSS for stylesheets or Copy Class for Tailwind CSS projects.

CSS SYNTAX EXPLAINED

How CSS Box-Shadow Works

The CSS property follows the syntax: box-shadow: [inset] offset-x offset-y blur-radius spread-radius color;

Blur Radius controls how diffused the shadow edge appears ($0\text{px}$ creates a sharp brutalist edge), while Spread Radius expands or contracts the shadow's footprint before blurring begins. Converting HEX colors to rgba(r, g, b, alpha) ensures smooth alpha blending over any background.
