HOW TO USE THIS PDF TOOLKIT

Merging, Splitting & Stamping PDFs Safely

  1. Merge Multiple Documents: In the Merge PDFs tab, select two or more PDF files, reorder them using the ↑ and ↓ buttons if needed, and click Merge & Download PDF.
  2. Extract Specific Pages: Switch to Split / Extract Pages, upload a PDF, and type the exact pages you need (such as 1-3, 6) to create a lightweight subset document.
  3. Rotate, Watermark & Number Pages: Use the third tab to fix sideways scanned pages, stamp diagonal watermark text across every sheet, or append automatic "Page X of Y" footers.

ZERO-UPLOAD PRIVACY

How Browser PDF Manipulation Works

Sensitive documents like bank statements, ID proofs, and legal contracts should never be uploaded to unknown third-party servers.

This tool processes binary PDF byte streams directly inside your browser's RAM using PDF-Lib, copying page trees, embedding standard Helvetica fonts, and generating a downloadable Blob without a single byte leaving your computer.
