HOW TO USE THIS TOOL

Picking, Converting & Testing Colors

  1. Select a Base Color: Use the Open Color Wheel picker, adjust the individual R, G, B sliders, type a 6-digit HEX code directly, or click Pick from Screen (on supported Chromium browsers) to sample any pixel on your monitor.
  2. Copy Any Format: Instantly grab the converted HEX, RGB, HSL, or CMYK string with one click.
  3. Verify Readability: Check the WCAG Text Contrast Checker to ensure your chosen background color passes AA ($4.5:1$) or AAA ($7.0:1$) accessibility standards with white or dark typography.
  4. Build Cohesive UI Palettes: Click any generated swatch in the Monochromatic Tints & Shades or Color Wheel Harmonies row to copy its HEX code immediately.

COLOR SCIENCE & WCAG

How We Calculate Color Models & Contrast

HEX & RGB represent additive light channels from $0$ to $255$ ($16^2 = 256$ levels per channel). HSL maps colors onto a $360^\circ$ cylindrical Hue wheel, making it easy to compute Complementary ($+180^\circ$), Analogous ($\pm 30^\circ$), and Triadic ($\pm 120^\circ$) harmonies.

WCAG Contrast Ratio is calculated from relative luminance ($L$) using the W3C formula: $\text{Ratio} = \frac{L_{\text{lighter}} + 0.05}{L_{\text{darker}} + 0.05}$.
