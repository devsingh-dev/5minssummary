USER GUIDE

How to Use This Audio Editor

  1. Upload Your Audio: Click the upload box and select any MP3, WAV, OGG, or M4A file from your device.
  2. Set Trim Markers: Use the Trim Start and Trim End sliders (or type exact seconds) to highlight the portion of the waveform you want to keep.
  3. Enhance & Adjust: Add a smooth Fade-In or Fade-Out transition, adjust the Volume Gain, or change the playback speed.
  4. Preview & Export: Click Preview Selection to listen to your edited clip, then click Download Trimmed Audio (.WAV) to save the file immediately.

CLIENT-SIDE TECHNOLOGY

How Browser Audio Processing Works

Unlike traditional tools that upload your private audio files to a remote server, this tool uses your browser's native Web Audio API and OfflineAudioContext.

Your audio is decoded into raw 32-bit floating-point PCM samples in local memory, sliced between your start and end timestamps, processed with linear gain ramps for fades, and encoded into a lossless 16-bit stereo .WAV file right on your device.
