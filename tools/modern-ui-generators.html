FRONTEND ARCHITECTURE

                
How Glassmorphism & Neumorphism Work

                

                    Glassmorphism relies on the CSS backdrop-filter: blur(Npx) property paired with a semi-transparent rgba() surface and a subtle $1\text{px}$ specular border highlight to create a frosted-glass optical effect.
                

                

                    Neumorphism (Soft UI) extrudes shapes from the background by pairing a negative-offset top-left highlight shadow with a positive-offset bottom-right ambient shadow.
